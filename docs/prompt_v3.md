# 《递归 RECURSION》v3 —— Skillry 式导演提示词

> 写法参照 Skillry / awesome-opus5-5-videos 里的高分作品（@alexwtlf、@koldo2k、@kgonia7、@astrothewizard 等）：
> 一个贯穿全片的形式概念；规定首帧和尾帧；逐秒写清镜头调度；写明哪些东西不要出现；规定光学参数；
> 要求制作过程中有检查环节；交付物写清楚。
> 下面的内容可以直接当作提示词交给 Opus 或视频生成工具，也可以作为我自己用代码实现时的规格说明。

---

## 形式概念（ONE FORMAL IDEA）
全片**只有一个镜头，没有任何剪切**：镜头以恒定的指数速度一路拉远，从一滴眼泪拉到可观测宇宙。
最后发现宇宙是一只眼睛的虹膜，而镜头正好停在第一帧的位置，首尾完全相接，可以无限循环。
每一层尺度都完整地嵌在上一层里，下一层出现的时候，上一层还在画面正中，只是已经缩小到只有一个像素大。

## 场景设定（SCENE CONTEXT）
公元 2300 年，黄昏。一个人坐在巨构城市一栋塔楼顶上的长椅上，面朝远方的地平线。
他的生活里已经什么都不缺。镜头从他右眼下眼睑的一滴泪开始，泪滴的表面倒映着整座城市。

## 视觉风格（LOOK）
- 写实 CG，质感像 IMAX 纪录片或者《沙丘》的空镜。不要卡通风格，不要扁平矢量，不要霓虹赛博朋克的滤镜感。
- 光线：全片只有一个主光源，就是低垂的太阳，从画面右后方打过来，形成逆光。暗部要真的暗下去。
- 调色：暗部是青灰色，高光是琥珀金。只用一种主色，只用一种强调色。
- 镜头质感：35mm 电影镜头；近景有浅景深，拉远以后慢慢变成全焦；加轻微的镜头呼吸感和胶片颗粒；泛光要克制。
- 所有东西都要物理可信：大气散射、体积雾、湿润表面的菲涅尔反射、太阳的临边昏暗、星系的尘埃吸收。

## 首帧（FIRST FRAME）
9:16 竖屏的微距画面。一滴泪挂在下眼睑的睫毛根部，占画面宽度的 40%，位于画面正中。
泪滴表面弯曲地倒映着黄昏的城市：金色的太阳和黑色的塔楼剪影。背景是虚焦的虹膜，青色纤维、金色内圈，瞳孔在画面上方三分之一处。

## 逐秒调度（恒定的指数拉远；每一层的时长和 log(缩放倍数) 成正比）
| 时间 | 画面宽度大约对应 | 画面里发生的事 |
|---|---|---|
| 0.0–2.0s | 3cm → 30cm | 泪滴 → 眼睛 → 半张脸。他没有眨眼。泪滴在 1.2 秒时滑落，出画 |
| 2.0–4.0s | 30cm → 30m | 人 → 长椅 → 屋顶。他很小，坐在长椅上，身旁的机器正在无声地为他递来一杯茶，他没有接 |
| 4.0–6.5s | 30m → 3km | 屋顶 → 塔楼 → 巨构城市。塔楼像珊瑚一样还在生长，塔尖的纳米机器群闪着光；飞行器的光带在雾里流动 |
| 6.5–9.0s | 3km → 3000km | 城市 → 大陆 → 地球的夜半球。城市灯光连成金色的网，晨昏线在右边；一圈轨道环绕着赤道 |
| 9.0–11.5s | 3000km → 100 万 km | 地球 → 月球轨道。月球表面布满发光的电路，它已经是一台计算机 |
| 11.5–14.0s | 100 万 km → 5 光时 | 太阳被戴森镜片包裹到 90%，缝隙里漏出金光。太阳系缩成一个点 |
| 14.0–17.0s | 5 光时 → 10 万光年 | 星空 → 银河系正对镜头。旋臂是青色的，核心是金色的，中心是一个黑洞 |
| 17.0–20.0s | 10 万光年 → 3cm | **反转**：银河系的形状和虹膜完全吻合。旋臂是虹膜纤维，核心的金光是虹膜内圈，黑洞是瞳孔。镜头停止拉远，发现我们一直在看的就是他的眼睛。最后一帧回到首帧，泪滴重新凝聚 |

## 不要出现的东西（DON'T）
- 不要剪切、不要淡入淡出、不要闪白。尺度之间的衔接只能靠几何上的嵌套。
- 不要任何 UI、HUD、全息界面，也不要“赛博朋克”式的霓虹字。
- 17 秒之前不要出现字幕；结尾字幕只有一行。
- 不要卡通人物，不要看得出是 AI 生成的脸：人物永远是剪影、背影或者局部特写。
- 不要让镜头速度忽快忽慢：必须是恒定的对数速度，只在最后 1.5 秒缓缓减速。

## 声音
- 全片是一个持续的低频，音高随尺度变大缓慢下降，从 80Hz 降到 30Hz。
- 城市那段有一层很远的环境声，每进入一个新尺度有一声极轻的高音泛音。
- 17 秒整：所有声音消失，只剩一声心跳。泪滴重新凝聚的那一刻，响起一声清脆的水滴声。

## 字幕（只有一行，19.0–19.8 秒，放在画面上方三分之一处，衬线字体）
> 是我们创造了它，还是它梦见了我们？

## 制作方式（HOW）
- 每一层尺度都是一个独立的渲染层：着色器 / Three.js / 光线步进。按“下一层的内容 = 上一层在画面中心的像素”的原则嵌套，拉远时按缩放倍数的对数计算每一层的透明度和 LOD。
- 写实素材如果可以用图像或视频生成工具，就生成后再用深度图分层做视差（参考 @koldo2k 的做法）；不能用的话，全部程序化生成。
- 21–22 秒的衔接：银河系的朝向、旋臂的相位、核心的颜色，必须和第一帧的虹膜一一对应。

## 检查环节（VERIFY）
- 每一层尺度都先出静帧，逐张严格检查；衔接处逐帧查看，不能有跳变、闪烁或穿帮。
- 第 0 帧和第 599 帧并排对比，差异必须肉眼不可见。
- 用数值检查音频：峰值不超过 −1 dBFS，响度大约 −14 LUFS。
- 不接受第一稿：找出最弱的一层，重做以后再整片渲染。

## 交付（DELIVER）
- 1080×1920、30fps、刚好 20.00 秒、可以无缝循环的 MP4（H.264 视频 + AAC 音频）
- 可以复现的源码，以及每一层尺度的静帧对比图

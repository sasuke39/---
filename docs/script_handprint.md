# 《手印》HANDPRINT —— 人类文明进化 · 20 秒竖屏短片 · 剧本 v2（纯代码版）

> 四万年来，人类一直在用自己时代的材料，画同一只手。

## 核心概念

**全片只有一个形状：一只手的轮廓。**
它永远在画面正中，大小、位置、姿势分毫不变。每过一个时代，这只手就被那个时代的**媒介**重新画一遍：岩壁颜料、泥土、楔形文字、石块、纸浆、活字、星图、齿轮、钨丝、X 光、月尘、像素、触屏，最后是 AI。

- **主题**：文明的进化，就是人类“留下印记”的方式的进化。
- **节奏就是主题**：镜头时长从 3 秒逐级缩短到 0.3 秒，观众从剪辑节奏本身就能感受到历史在加速。
- **为什么适合纯代码**：手形是一条精确的矢量轮廓（SDF 遮罩），每一镜只是换一种程序化“材质”去填充或勾勒它。代码能把每一个像素控制到位，前后镜头的手形严丝合缝，剪切点落在同一帧。这正是代码比实拍和 AI 视频强的地方。

## 伏笔与反转

- 第 14 镜“AI 去噪”的最后一帧，手多出了一根手指，但只停留 2 帧，第一遍几乎没人能发现。
- 第 16 镜岩壁上清清楚楚出现六指手印，观众会回头重看。这既拉高完播率，评论区也会出现“回去看第 13 秒”。
- 六根手指是“AI 画不好手”这个家喻户晓的梗，不用任何解释，观众就知道这一次留下手印的是谁。

**备选结尾（更温暖）**：第 16 镜里，新手印和四万年前那个完全一样，只是颜料换成了发光的星尘。字幕改为“四万年了，我们还在留下手印。”

## 视觉统一规则

1. 手形固定：同一条矢量轮廓，掌心朝向镜头，五指自然张开，占画面宽度的 50%，位于画面中部。
2. 主光源永远从左上方来，变化的只是光的颜色和质感。
3. 每一镜的材质都要有真实感：法线光照、体积颗粒、景深、胶片颗粒。拒绝扁平矢量。
4. 色调随时代变化：火光的橙红 → 泥土的赭黄 → 正午的白金 → 烛光 → 夜蓝 → 工业灰 → 白炽 → 纯白 → 月面黑白 → 显示器的绿 → 屏幕的冷白 → AI 的彩色噪点 → 回到火光。

## 声音

- 不用配乐。每一镜的触碰声自然组成一段越来越快的鼓点，在频闪处到达顶峰，然后断成完全的寂静。
- 结尾只剩火苗声和呼吸声，并接回开头。
- 全部声音由代码合成，和画面帧级对齐。

# 《手印》HANDPRINT —— 人类文明进化 · 20 秒竖屏短片 · 剧本 v1

> 一只手，四万年。

## 核心概念

**全片只拍一只手。**
每个镜头里，这只手都在画面的同一个位置、同样的大小，做着它那个时代最重要的一个动作。
每次剪切都落在手**触碰到东西的那一瞬间**，所以每一次触碰都是一个鼓点。

**剪辑节奏本身就是主题。**
镜头时长按几何级数缩短：第一个镜头 3 秒，最后一个只有 0.3 秒。
观众不需要任何解说，就能从节奏里感觉到“文明在加速”。

**结尾回到原点。**
最后一个镜头回到四万年前的那面岩壁，片子首尾相接，可以无限循环。

## 为什么是“六根手指”

- **一眼就懂。** 六根手指是“AI 生成的图画不好手”这个梗，几乎所有刷短视频的人都认得。不用任何解释，观众就知道这只手是谁的。
- **天然带评论。** 一定会有人在评论区写“数一数手指”“细思极恐”，这会推高完播率和互动。
- **主题上闭环。** 四万年来每一个手印都是人类留下的，第一次有一个手印不是。这正好回答了片子的问题：文明的下一棒，交给了谁。

**备选结尾 A（更温暖）**：第 16 个镜头改为星际飞船的舷窗，窗外是一颗陌生的星球。一个孩子对着玻璃哈气，用手按上去，雾气里留下的手印和四万年前那个一模一样。字幕改为“四万年了，我们还在留下手印。”

## 节奏与声音

- **镜头时长**：3.0 → 2.0 → 1.5 → 1.2 → 1.0 → 0.85 → 0.7 → 0.6 → 0.5 → (0.6) → 0.45 → 0.35 → 0.3 → 0.3 秒，逐级加速。1945 年那一镜故意多停 0.1 秒，作为全片的“刹车点”。
- **声音**：不用配乐。所有的“音乐”都来自每一次触碰的声音，它们自然排成一段越来越快的鼓点，在频闪处达到顶峰，然后断成完全的寂静。结尾只有火苗声和呼吸声。
- **循环**：结尾的呼吸声和火光直接接上开头。

## 画面一致性规则（拍摄或生成时必须遵守）

1. 手永远在画面正中，占画面宽度的 45% 左右，手腕从画面下方伸进来。
2. 主光源永远从画面左上方打过来，变化的只是光的颜色和质感。
3. 每一镜的第一帧都是“手即将碰到东西”，剪切点都是“碰到的那一瞬间”。
4. 第 1 镜和第 16 镜的岩壁、构图、光线完全相同，只多了一个手印。

## 制作建议（待确认）

- **画面**：真实的手、火光、蒸汽、纸浆，纯代码做不出照片级质感。建议每个镜头先生成一张关键帧，再用可灵、即梦、Seedance 这类工具做“图生视频”，每段 1 到 3 秒。
- **剪辑、计数器、频闪、声音**：由我用代码精确完成，帧级对齐每一个鼓点。

# 《递归 RECURSION》分镜脚本

- **时长**：20 秒 · **画幅**：9:16 竖屏（1080×1920）· **帧率**：30fps
- **平台**：TikTok / 抖音 / Reels（首尾无缝循环，自动重播时看不出接缝）
- **一句话**：镜头钻进一只人类的眼睛，穿过 AI 文明的九层奇观，一路拉远到星系尺度——最后星系睁开眼，正是开头那只眼睛。

> **是我们创造了它，还是它梦见了我们？**

## 结构与节奏

| 段落 | 时间 | 节奏 | 视觉质感 | 声音 |
|---|---|---|---|---|
| 吸入 | 0–1.3s | 静 → 冲刺 | 真实的人眼 | 呼吸般的风声上扬 |
| 奇观（人的尺度） | 1.3–9.6s | 越切越快（1.9s → 1.3s 一幕） | 有机、湿润、发光 | 和声渐强 + 越来越密的滴答 + 每次转场一记重击 |
| 拉远（宇宙尺度） | 9.6–15.6s | 一镜到底式的持续拉远 | 几何、冷、电路 | 音乐**突然切断**，只剩下沉的低频嗡鸣 |
| 回归 | 15.6–20s | 慢 | 星系 → 眼睛 | 心跳 → 近乎寂静 |

### 画面安全区（TikTok）
- 左上角的场景字幕放在 y≈300 到 400 之间，避开顶部的“关注 / 推荐”栏。
- 结尾字幕放在 y≈1330 到 1500 之间，避开底部的文案区和右侧的点赞栏。
- 主体画面都放在画幅的中间偏上。

## 声音设计

| 时间 | 声音 |
|---|---|
| 0–1.3s | 低通噪声逐渐打开，像一次吸气 |
| 1.3–9.6s | A 小调加九的和声逐渐变强。滴答声的间隔从 0.32 秒缩短到 0.065 秒，每次转场有一记低频重击和一声高音铃 |
| **9.6s** | **音乐突然切断**，这是片子节奏上的转折点 |
| 9.6–16.4s | 频率从 70Hz 降到 36Hz 的低频嗡鸣，加上宇宙风声，11.4 和 13.3 秒处各有一记较轻的重击 |
| 16.45s | 心跳（宇宙之眼闭成一道缝） |
| 17.55s | 心跳（回到人类的眼睛） |
| 17.4–20s | 近乎寂静，只有很轻的高音，并且延续到开头，让循环听不出接缝 |

配乐和音效都由 `film/audio.py` 合成。如果换成商用配乐，也建议保留 **9.6 秒处的断音**和**两声心跳**。

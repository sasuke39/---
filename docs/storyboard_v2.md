# 《递归 RECURSION》写实版 v2 —— 分镜与制作说明

- **时长** 20 秒 · **画幅** 9:16（1080×1920）· 30fps · 首尾无缝循环
- **做法**：每个镜头都是一个 GLSL 着色器，用光线步进和体积渲染在浏览器里逐帧算出 HDR 画面，再经过后期处理（泛光、ACES 调色、色差、暗角、胶片颗粒），最后用 ffmpeg 编码。
- **和 v1 的区别**：v1 是扁平的 2D 矢量动画；v2 全部改成有真实光影、雾和体积感的 CG 画面，镜头更少、更慢、更有分量。

## 分镜

| # | 时间 | 镜头 | 字幕 | 技术要点 |
|---|---|---|---|---|
| 1 | 0–3.2s | 人眼微距：虹膜纤维、角膜湿润的高光。镜头慢慢推进，然后冲进瞳孔，瞳孔深处亮起远方城市的灯光 | — | 程序化虹膜，用高度场法线做光照；柔光箱反射；睫毛分三排 |
| 2 | 3.2–7.4s | 暮色雾中的有机巨构城市。塔楼从地面“长”出来，塔尖有纳米机器形成的亮带；逆光剪影、飞行器光带、空中光环。镜头从街道一路升到塔顶 | 城市，在自己生长 | SDF 光线步进（查询 3×3 邻域）；解析高度雾；航道光带 |
| 3 | 7.4–11.2s | 近地轨道，地球夜面：城市灯光网络，日出时的大气光边。月球上的电路从一个火花开始向外蔓延，最后覆盖整个月面 | 月球，成了一台计算机 | 解析球体求交；大气散射近似；经纬网格电路 |
| 4 | 11.2–14.6s | 太阳表面的米粒组织和日珥。暗色金属镜片从一侧开始包裹太阳，缝隙里漏出金光，镜头拉远看到完整的戴森球 | 太阳，被完全包裹 | 3D Voronoi 镜片；双层壳；日冕 |
| 5 | 14.6–17.8s | 从星系盘内部一路拉远，再转成正对的视角：旋臂、尘埃带、粉色星云、恒星。星系中心出现一个黑洞 | 整个星系，成了一颗大脑 | 72 步体积积分（发光加吸收）；盘面上的星点；黑洞的光子环 |
| 6 | 17.8–20s | 黑洞变成瞳孔，画面回到开头那只人眼。虹膜里先闪过金色的 AI 电路，然后慢慢褪去 | **是我们创造了它，/ 还是它梦见了我们？** | 最后一帧和第一帧相同，可以循环 |

**画面衔接**：瞳孔的黑对应城市的夜，城市升空接到地球轨道，太阳接到星系里的一颗星，星系中心的黑洞对应瞳孔。所有字幕都放在画面上方三分之一处，避开抖音和 TikTok 底部的文案区和右侧的按钮栏。

## 声音

| 时间 | 内容 |
|---|---|
| 0–3.2s | 呼吸般的噪声，加上冲进瞳孔时不断上扬的滑音 |
| 3.2s | 重击 |
| 3.2–14.6s | A 小调弦乐铺底逐渐变强；低鼓从 0.9 秒一下加快到 0.28 秒一下；每次转场前有一声反向吸气，转场时一记重击加一声高音铃 |
| 14.6s | 全部抽空 |
| 14.6–17.3s | 星系尺度的低鸣，加上空灵的和声 |
| 17.25s、18.3s | 两声心跳（星系睁眼、回到人眼） |
| 结尾 | 微弱的高音，延续到开头，让循环听不出接缝 |

## 重新渲染

```bash
python3 v2/audio.py                          # 生成 out/recursion_v2_audio.wav
node v2/render.mjs                           # 生成 out/recursion_v2_9x16.mp4（CPU 上大约 30–50 分钟）
node v2/render.mjs --stills 0,5.5,9,13,16.8  # 只导出指定时间点的静帧，用来检查画面
```

直接用浏览器打开 `v2/film.html?scale=0.5`，可以低分辨率实时预览（需要 GPU）。
